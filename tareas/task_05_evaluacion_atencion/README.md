# Task 05 · Exactitud e interpretabilidad

La atención aporta su mayor ventaja dentro del rango en cuatro cifras: **70.33 %** frente a **50.00 %**.
En una o dos cifras el resumen fijo retiene suficiente información; conforme crece la secuencia aparece
el cuello de botella. Las cifras cinco y seis son fuera de distribución y muestran que la atención no
produce por sí sola extrapolación algorítmica.

Los mapas se interpretan como alineaciones aprendidas, no como demostración de una regla simbólica.
